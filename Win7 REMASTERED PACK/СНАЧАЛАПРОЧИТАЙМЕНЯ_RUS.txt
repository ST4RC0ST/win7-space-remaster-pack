          WINDOWS 7 REMASTERED PACK (КОДОВОЕ НАЗВАНИЕ: SPACE)

                      Версия 1.0 — Фан-проект

                            О проекте
Windows (кодовое название: SPACE) — фанатский набор для Windows (7, 8, 8.1, 10, Server 2016),
включающий авторские обои и анимированную заставку (скринсейвер) с музыкальным сопровождением.

                                Состав
Обои — изображения, созданные автором.
Заставка (ScreenSaver) — анимированная заставка со звуком.

                        Установка заставки
Установите программу «Any Video Screensaver».
Откройте настройки заставки в Windows.
Выберите «Any Video Screensaver» в качестве заставки и нажмите «Параметры» (Options).
В открывшемся окне укажите путь к видеофайлу, затем закройте окно. 
Если заставка запускается — значит, всё сделано правильно.

                          Возможные проблемы
Если появилось сообщение «Video file not found» («Видеофайл не найден»), 
повторно укажите путь к видеофайлу в настройках заставки.
